# 시장 시뮬레이션 모형 v0.4.0

2026-10-22. 구현한 모형은 `market-2`이며, 실측 시세로 계수를 추정한 예측 모형은 아니다. 같은 시나리오에서 참가자 구성·유동성·뉴스·주문·비용을 바꿔 비교하는 실험 도구다.

## 반영한 시장 특성과 근거

## 네 단계 구현

1. **가격·참가자 행동**: 위험감수에 비례하던 큰 틱별 호가 오차를 줄였다. 참가자의 판단 시점을 분산하고 감정 충격을 제한했다. 시장 전체의 확률적 가치 추정·변동성 상태와 개별 주문 선호를 분리했다. 개인·종목·틱·용도별 난수로 추가 주문에 따른 무관한 난수 소비를 막았다.
2. **발행주식·호가**: 기본 발행주식은 종목당 1천만 주다. 초기 참가자 배분은 발행주식의 35% 이내이고 초과 수요는 비례 배분한다. 미배분 주식은 배경 계좌가 가진다. EPS·BPS는 참가자 재산이나 종목 수에 따라 바뀌지 않는다. 가격·시간 우선, 도착 시 기존 호가 체결, 부분 체결, 미체결 지정가 유지, 자기 체결 방지, 유한한 대주 풀을 적용했다.
3. **거래일·안정장치**: 09:00~15:30, 10초 단위의 가상 거래일을 둔다. 다음 거래일에 전일 기준가·발동 횟수를 갱신하고 자산은 이어간다. 당일 주문은 장 마감에 만료한다. 일반 주식 호가 단위와 ±30% 가격제한, VI 2분 단일가, CB 1·2단계 중단 뒤 10분 단일가, 3단계 당일 종료를 구현했다. 단일가는 실행 여력을 반영한 최대 체결량·최소 불균형·직전가 근접 순서다.
4. **뉴스·비용·저장**: 발표된 가치 변화는 관심 종료 후에도 유지한다. 거시 변화는 현재 실험을 초기화하지 않고 예약한다. 편도 기본 1.5bp 수수료를 체결 때, 차입·공매도 기본 연 5%를 장 마감에 252거래일 기준으로 정산한다. 비용은 별도 계정으로 이동해 현금 보존을 검증한다. 설정·조작·시점·모형 버전을 JSON으로 저장하며, 다시 재생해 계좌·호가·미래 난수까지 복원한다. 전체 체결 CSV와 전체 분봉을 보관한다.

## 사용법

- 시뮬레이션 상단 **실험실**에서 발행주식·호가 잔량·변동성·수수료·이율·대주 한도를 설정한다. **모형 적용 · 새 실험 시작**은 현재 실험을 초기화한다.
- **배경 시장 끄기**는 설정한 참가자와 사용자의 주문만 거래하게 한다. 모두 관망하면 체결·가격 변화가 없다. 미배분 발행주식의 소유는 수동 배경 계좌에 남는다.
- **거시경제 변화 예약**은 현재 계좌와 진행 시점을 유지한다. 예약 시간은 거래 시간 기준이다.
- **브라우저에 저장** 또는 **실험 JSON 내보내기**로 진행 상태를 보관한다. 새로고침 시 자동으로 보존하는 것은 설정뿐이다. 저장본을 불러오면 기록된 조작을 재생한다.
- **전체 체결 CSV**는 화면의 최근 40건 제한과 무관하다. 필드는 종목 ID·거래 틱·가격·수량·매수자·매도자·편도 비용·단일가 여부다.
- 장 마감 뒤 **다음 거래일**을 누른다. 무제한 자금도 실제 유동성·대주 재고·거래시간을 지켜야 한다. 무제한 자금은 유한한 현금 흐름 원장으로 기록하여 `Infinity − Infinity`를 만들지 않는다.

## 재현과 검증

```powershell
python scripts/build.py
node scripts/verify-market-realism.cjs
node scripts/verify-simulation-controls.cjs
node scripts/verify-simulation-trading.cjs
python -m http.server 8876 --bind 127.0.0.1 --directory dist
# 다른 터미널
node scripts/verify-market-browser.cjs
```

`verify-market-realism.cjs`는 기본 30개 시드 × 390분 × 3종목, 저유동성·고변동성·100명·뉴스 제거 조건을 검사한다. 매 틱 현금+비용 계정, 순주식, 정수 가격·현금, 가격제한, 대주 수량을 검증한다. 별도로 개인/집단 주문 충격, 지속 호가, 체결 우선순위, VI, CB, 장 전환, 발표 전 정보, 거시 예약, 저장·복원을 검사한다. 브라우저 검사는 저장·파일 내보내기/불러오기·실제 주문·장 전환·설정·거시 예약·경로 이동, 4개 화면 크기를 포함한다.

결과 원본: `artifacts/market-upgrade-20261022/results.json`, `browser-results.json`. 과거 기준은 `artifacts/market-audit-20261021/realism-results.json`의 기본 30개 시드다. 전후 기본 모형을 비교하므로 하나의 매개변수만 바꾼 인과 추정은 아니다. 분봉 방향 전환은 수익률이 0인 분을 제외하며, 같은 방향 최장 길이도 0인 분을 건너뛴다. 작은 주문 충격은 같은 난수의 무주문 경로와 호가 중간값을 비교하며 매수·매도 체결가 차이와 구분한다.

## 한계와 후속 보정

- 한국 개별 주식에 가까운 교육·실험 모형이다. 선물, 시장별 상품·시간대 예외, 별도의 시가·종가 단일가와 장외 거래는 구현하지 않았다. VI 기준도 일반 종목 기준으로 단순화했다.
- 배경 시장의 8개 계좌가 다수 유동성을 대표한다. 체결·취소·신규 주문 전체를 이용한 실증 OFI 모형의 추정 결과는 아니다. 임팩트 기억은 공격적 체결의 순방향 수량을 깊이로 나눈 근사치다.
- 동일 틱의 종목 간 현금 배분은 ID 순서다. 표시 순서에는 독립적이지만 완전한 동시 다종목 주문·배분 시스템은 아니다.
- 단기 수익률에는 호가 단위와 매수·매도 체결가 교대에 따른 음의 자기상관이 남는다. 실제 시세 표본으로 변동성·스프레드·거래량·수익률 꼬리·자기상관·상관행렬을 공동 보정하는 단계가 필요하다. 기본 일 변동성 입력은 가치 추정의 혁신 크기이며 실현 변동성의 보장값이 아니다.
- 개별 대주자의 계약·리콜, 세금·배당·분할·부도 정리, 지연 통신과 주문 취소 경쟁은 미포함이다. 무제한 자금은 실험 기능이다.
- 재생은 모형 버전이 같아야 한다. 현재 불러오기 한도는 100거래일·조작 10,000개·JSON 파일 5MB다. 길거나 큰 실험은 복원 시간이 늘어난다.

앱의 실행 경로는 `SecuritiesSimulation → LiquidMarketSimulation`이다. 기존 `MarketSimulation`은 참가자 규칙·뉴스·재무 계산의 기반과 저수준 단위 검사에 남아 있다. 따라서 기존 기반 엔진 검사 통과와 새 시장 모형의 현실성 검증을 구분한다.
