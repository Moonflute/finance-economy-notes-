# 증권시장 시뮬레이션 · 속성 및 상호작용

이 문서는 현재 구현한 모형을 설명합니다. 앱의 열 제목 설명과 ‘속성·규칙’ 안내는 같은 `site/simulation-help.js`를 사용합니다. 범위·누락값은 엔진의 속성 정의에서 가져옵니다.

## 시장 작동·판단 순서

### 판단 우선순위

거래 중단 → 반대매매 → 순자산·직접 계좌 확인 → 안정장치 참여 추첨 → 감정 → 기업 소식 → 거래량 → 상승·하락 기본 행동 순으로 판단합니다. 먼저 선택된 대응 하나로 목표 보유량을 정합니다.

감정 추첨에 실패하면 소식으로, 소식의 유효 영향이 없으면 거래량으로 넘어갑니다. 거래량에도 반응하지 않으면 기본 가격 행동을 추첨합니다. 여러 행동을 동시에 더해 주문하지 않습니다.

### 가상 10초의 진행

한 틱은 가상 10초입니다. 이미 확정된 가격·체결로 감정을 갱신하고 판단한 뒤, 주문을 제출·매칭·정산합니다. 현재 틱의 체결은 다음 틱부터 참여자가 관찰합니다.

모든 종목이 같은 시계를 쓰며 표시 순서대로 거래합니다. 전체 종목 체결 뒤 안정장치 조건을 확인하므로 새 발동 효과는 다음 틱부터 적용됩니다. 시간을 멈추면 새 거래도 일어나지 않습니다.

### 80% 확률의 의미

0 이상 1 미만 난수가 0.8보다 작으면 80% 행동을 선택합니다. 10번 중 반드시 8번을 실행하는 할당은 아닙니다. 같은 설정·시드·직접 개입 순서는 같은 결과를 만듭니다.

가격·거래량·감정 반응은 조건을 만족하는 틱마다 추첨합니다. 기업 소식은 사건별 정보 단계마다 한 번 추첨합니다. 행동을 선택해도 목표 차이·주문 한도·상대 호가에 따라 미체결될 수 있습니다.

### 주가·체결·거래량

매수 지정가가 매도 지정가 이상이면 두 가격의 중간을 원 단위로 계산해 체결합니다. 주가는 실제 체결 가격으로 바뀌고 거래량은 체결 주식 수를 더합니다. 상대 주문이 없으면 가격은 유지되고 거래량은 늘지 않습니다.

체결 때 현금과 주식이 상대 계좌로 이동합니다. 목표 수량을 한 번에 모두 주문하지 않고 위험감수·행동 강도·안정장치에 따라 일부를 제출합니다. AI의 미체결 호가는 다음 틱에 새로 냅니다.

### 여러 종목의 상호작용

기본 종목은 필드테크·데일리생활·프라임산업이며 추가 종목은 최대 5개입니다. 종목마다 가격·호가·차트·재무·소식·개인 감정이 따로 있고, 같은 사람의 현금·차입·담보는 공유합니다.

초기 주식 비중과 종목별 목표는 종목 수로 나눕니다. 한 종목의 손익은 계좌 순자산을 바꾸고 다른 종목의 주문·담보·감정에도 영향을 줄 수 있습니다. 앞 종목 체결은 뒤 종목의 가용 자금을 바꿉니다.

## 참여자 구성·표 편집

### 인원 배정과 자동 채움

전체 인원은 2~100명입니다. 속성마다 유형별 인원을 넣고 표 생성을 누르면 실제 개인 행을 만듭니다. 빈 배정 칸은 남은 인원을 기본 분포에 맞춰 자동으로 나눕니다. 입력 합계가 전체를 넘으면 오류를 표시합니다.

속성은 각각 배분한 뒤 시드로 섞어 조합합니다. 위험 선호 20명·고액 자산가 20명을 지정해도 같은 20명이 되는 것은 아닙니다. 표의 현재 인원과 배정 인원으로 차이를 확인합니다.

### 개별 수정과 적용

셀을 고치면 파란색으로 표시하고 자동 생성보다 우선합니다. 셀을 비우거나 선택값을 자동으로 바꾸면 자동값을 복원합니다. 행 끝의 ↺는 그 사람의 모든 직접 수정값을 자동으로 돌립니다.

표 생성은 편집 중인 구성을 바꿉니다. 설정 적용 · 새로 시작을 눌러야 시장에 반영되고 실험도 처음부터 시작합니다. 변경 취소는 진행 중인 시장의 설정을 되돌려 불러옵니다.

### 속성별 비율과 기본값

비율 설정은 자금이 아닌 사람 수 기준입니다. 속성별 합계를 100%로 맞추면 정수 인원으로 환산하며, 생성 후 개별 수정도 가능합니다. 수동 수정값을 우선하므로 실제 분포는 배정 목표와 달라질 수 있습니다.

속성 안내의 누락 시 값은 저장된 속성이 없을 때의 보완값입니다. 예시 참여자의 값이나 자동 배정 결과와는 다를 수 있습니다. 열 제목은 마우스·키보드 초점·터치로 설명을 열 수 있습니다.

## 참여자 · 재산·위험

### 초기 재산

100~10,000,000 만원 · 누락 시 10,000 만원

실험을 시작할 때 가진 총재산입니다. 입력 단위는 만원이며 현금과 초기 보유 주식으로 나눕니다.

모든 종목이 한 계좌의 현금·차입·담보를 공유합니다. 같은 성향이라도 재산이 크면 주문 가능한 금액이 커집니다.

자동 배정 유형: 소액 자산가 = 1,000 만원 / 중간 자산가 = 10,000 만원 / 고액 자산가 = 50,000 만원. 각 유형의 인원을 지정하고 남는 인원은 자동 배분합니다.

### 위험감수

0~100 % · 누락 시 50 %

높을수록 목표 투자 비중과 주문량·호가의 적극성이 커집니다. 매수할 확률 자체를 뜻하지는 않습니다.

상승·하락 행동의 실행 확률은 별도로 설정합니다. 위험감수가 높아도 최대 레버리지·신용·담보 한도를 넘을 수 없습니다.

자동 배정 유형: 위험 회피형 = 20 % / 위험 중립형 = 50 % / 위험 선호형 = 85 %. 각 유형의 인원을 지정하고 남는 인원은 자동 배분합니다.

### 초기 주식 비중

0~100 % · 누락 시 50 %

초기 재산 중 주식에 넣을 비율입니다. 전체 종목에 균등 배분하고 나머지는 현금으로 둡니다.

‘초기 비중 유지’의 목표와 기업 소식 대응의 기준 비중으로도 사용합니다. 주식 수는 정수로 계산하므로 남는 금액은 현금입니다.

자동 배정 유형: 현금 중심 = 20 % / 균형 배분 = 50 % / 주식 중심 = 80 %. 각 유형의 인원을 지정하고 남는 인원은 자동 배분합니다.

### 최대 레버리지

1~3 배 · 누락 시 2 배

전체 계좌에서 허용할 최대 투자 배수입니다. 1배는 신규 차입 없이, 2배는 순자산의 최대 2배까지 투자합니다.

신규 차입은 초기 재산 × (최대 배수 − 1)로도 제한합니다. 총 포지션이 순자산 × 최대 배수 × 1.12를 넘으면 반대매매를 시도합니다.

자동 배정 유형: 차입 없이 투자 = 1 배 / 2배까지 허용 = 2 배 / 3배까지 허용 = 3 배. 각 유형의 인원을 지정하고 남는 인원은 자동 배분합니다.

## 참여자 · 가격 대응

### 상승할 때

선택 7가지 · 누락 시 매수

최근 1분의 가격 방향이 상승일 때 사용할 기본 행동입니다. 가격 변화가 없을 때도 이 설정을 사용합니다.

매 틱 차이의 회복력 × 0.25만큼 평소 값으로 돌아간 뒤 새 충격을 반영합니다. 20%면 틱당 차이의 5%를 회복합니다.

자동 배정 유형: 느린 진정 · 5% = 5 % / 보통 진정 · 20% = 20 % / 빠른 진정 · 60% = 60 %. 각 유형의 인원을 지정하고 남는 인원은 자동 배분합니다.

### 감정 반응 확률

0~100 % · 누락 시 70 %

개인 감정이 공포·탐욕 기준에 닿았을 때 매 틱 감정 행동을 선택할 확률입니다. 0%면 감정 주문을 하지 않습니다.

추첨에 실패하면 기업 소식 → 거래량 → 기본 가격 대응으로 넘어갑니다. 기준에 닿지 않았을 때는 이 확률로 별도 추첨하지 않습니다.

자동 배정 유형: 반응 확률 0% = 0 % / 반응 확률 50% = 50 % / 반응 확률 80% = 80 % / 항상 반응 = 100 %. 각 유형의 인원을 지정하고 남는 인원은 자동 배분합니다.

### 공포 반응 기준

0~49 점 이하 · 누락 시 25 점 이하

현재 감정이 이 점수 이하이면 공포 반응을 추첨합니다. 기준을 높이면 덜 두려운 상태에서도 반응합니다.

기준 25점이면 25점부터 공포 행동 대상입니다. 따르기·역행·관망 중 실제 행동은 감정 대응 성향과 반응 확률로 정합니다.

자동 배정 유형: 15점 이하부터 = 15 점 이하 / 25점 이하부터 = 25 점 이하 / 35점 이하부터 = 35 점 이하. 각 유형의 인원을 지정하고 남는 인원은 자동 배분합니다.

### 탐욕 반응 기준

51~100 점 이상 · 누락 시 75 점 이상

현재 감정이 이 점수 이상이면 탐욕 반응을 추첨합니다. 기준을 낮추면 더 일찍 탐욕에 반응합니다.

기준 75점이면 75점부터 대상입니다. 감정 따르기는 매수, 역행은 매도하고 공포 관망형은 탐욕만으로 별도 행동하지 않습니다.

자동 배정 유형: 65점 이상부터 = 65 점 이상 / 75점 이상부터 = 75 점 이상 / 85점 이상부터 = 85 점 이상. 각 유형의 인원을 지정하고 남는 인원은 자동 배분합니다.

## 기업 소식·이슈의 상호작용

### 기대·내부정보·발표

사전 기대 공개 → 허용된 내부자의 실제 내용 인지 → 공개 발표 순으로 정보를 전달합니다. 단계마다 개인 지연을 적용합니다. 공개 정보 참여자는 발표 전에 실제 내용을 활용하지 않습니다.

예를 들어 기대 +6%·실제 −7%인 이슈는 선제 매수 뒤 발표 후 매도로 바뀔 수 있습니다. 실제가 양수여도 기대보다 약해 목표 비중이 낮아지면 수익실현 매도가 나올 수 있습니다.

### 소식이 바꾸는 것

소식의 방향·강도·유효 기간으로 목표 비중과 지정가 판단을 정합니다. 수락한 영향이 0이 아니면 거래량·기본 가격 행동보다 우선합니다. 감정 행동이 선택되면 소식보다 먼저 적용합니다.

소식은 재무제표나 계좌 현금을 자동으로 바꾸지 않습니다. 호재가 있어도 매수 자금·매도 상대가 부족하면 거래가 없을 수 있습니다. 여러 유효 소식은 해석한 영향을 합산합니다.

### 실행 중 이슈 발동

차트의 기업 이슈 또는 기업 정보 → 기업 소식 → 이슈 발동에서 현재 종목에 사건을 추가합니다. 발표 대기 0분은 즉시 공개하며, 예정 이슈는 지금 발표로 앞당길 수 있습니다.

실행 중 이슈는 종목당 30개까지 추가할 수 있고 초기화·설정 적용·새로고침 때 사라집니다. 미리 저장할 예정 소식은 회사별 설정에서 최대 20개를 등록합니다. 인지 현황은 정보 인지와 실제 행동을 구분해 보여줍니다.

실험 시작 후 공개 발표하는 가상 분입니다. 예정 소식은 1~1,440분에 설정하고, 실행 중 이슈의 대기 0분은 즉시 발표합니다.

### 사전 기대 공개

0~1,440 발표 전 분

발표 몇 분 전부터 기대를 공개할지 정합니다. 0분은 사전 기대 없이 발표합니다. 발표 시점보다 길게 설정할 수 없습니다.

### 발표 후 관심 기간

1~120 분

공개 발표 뒤 관심이 남는 시간입니다. 그동안 소식의 영향이 점차 줄고 기간이 끝나면 뉴스 판단에서 빠집니다.

### 발표 전 기대

-30~30 %

발표 전 공개되는 기대의 가치 변화율입니다. 양수는 호재 기대, 음수는 악재 기대이며 선제 대응·반대 해석형이 활용합니다.

### 실제 발표 내용

-30~30 %

실제 발표 내용의 가치 변화율입니다. 발표 전에는 허용된 내부자만, 발표 뒤에는 공개 정보 참여자도 개인 지연 이후 알 수 있습니다. 주가를 이 비율만큼 강제로 바꾸지 않습니다.

### 발표 전 내부정보

선택 2가지 · 누락 시 아무도 모름

일부 참여자 인지를 켜야 사전 내부정보가 전달됩니다. 아무도 모름이면 개인의 사전 인지자 설정도 적용하지 않습니다.

### 내부정보 전달

0~1,440 발표 전 분 · 누락 시 1 발표 전 분

발표 몇 분 전에 실제 내용을 내부자에게 전달할지 정합니다. 개인의 반응 지연을 추가 적용하며 0분이면 발표 전 활용할 시간이 없습니다.

### 자동 배정 비율

0~100 % · 누락 시 20 %

개인 정보 접근이 자동인 사람 중 사전 인지자로 뽑을 비율입니다. 자동 인원 × 비율을 반올림해 시드 순서로 배정합니다. 명시한 사전 인지자·공개 정보만은 이 추첨보다 우선합니다.

## 거래량의 상호작용

### 거래량 배수 계산

종목별 실제 체결의 최근 1분 합계를 그 앞 최대 5분의 1분 평균으로 나눕니다. 거래 가능한 시간이 최소 2분 쌓이고 이전 평균이 0보다 커야 배수를 계산합니다. 중단 시간은 비교에서 제외합니다.

내 직접 체결도 거래량에 포함됩니다. 현재 틱의 체결은 다음 판단부터 반영하며, 이전 평균이 0일 때 무한대 급증을 만들지 않습니다. 공통 화면은 2배 이상 급증·0.5배 이하 위축을 표시합니다.

### 거래량 → 행동 → 체결

상승과 거래량 급증이 겹치면 추종형은 매수하고 역행형은 매도하려 합니다. 하락 급증에서는 방향을 뒤집습니다. 가격 방향이 없으면 추종·역행은 별도 행동하지 않습니다.

보유 축소형은 급증 때 매수·공매도 포지션을 줄입니다. 관망형은 저거래량 때 쉽니다. 실제 체결이 늘면 다음 틱의 신호가 달라져 다시 행동에 영향을 줄 수 있습니다.

## 감정의 상호작용

### 감정 변화와 전염

개인 감정은 평소 감정에서 시작해 확정된 1분 추세·직전 가격 변화·최근 6분 고점 대비 하락·계좌 손익·직전 군중 평균의 영향을 받습니다. 같은 비율이면 손실 충격을 이익보다 크게 반영합니다.

급증한 거래량은 가격 충격을 증폭합니다. 모두 직전 군중 평균을 보므로 계산 순서에 따라 전염이 달라지지 않습니다. 점수는 0~100 안에 유지하며 거래 중단 중에는 회복만 진행합니다.

### 패닉셀과 추격 매수

공포 기준 이하에서 따르기형이 반응하면 보유 매수 주식을 줄입니다. 이 패닉셀은 새 공매도를 만들거나 기존 공매도를 늘리지 않습니다. 탐욕 기준 이상에서는 매수를 늘리려 합니다.

역행형은 공포 매수·탐욕 매도, 공포 관망형은 공포에 거래를 쉽니다. 실제 체결로 가격·손익이 변하면 다음 틱 감정도 바뀝니다. 강도가 높아도 현금·레버리지·상대 호가는 필요합니다.

### 시장 공포·탐욕 지수

차트의 심리 또는 체결·분석 → 시장 심리에서 봅니다. 선택 종목의 AI 참여자 점수 단순 평균으로, 재산 가중치와 내 직접 계좌는 포함하지 않습니다. 개인 이름을 누르면 해당 감정 설정으로 이동합니다.

화면 구간은 25 이하 극단적 공포, 40 미만 공포, 60 미만 중립, 75 미만 탐욕, 그 이상 극단적 탐욕입니다. 개인 행동은 이 공통 구간이 아닌 각자의 공포·탐욕 기준을 사용합니다.

## 기업 · 재무 속성·지표

### 연간 매출액

0~1,000,000 억원 · 누락 시 10 억원

입력한 연간 매출입니다. 이익률의 분모와 거시경제 시나리오의 매출·비용 추정에 사용합니다. 실행 중 자동으로 누적하지 않습니다.

### 연간 영업이익

-1,000,000~1,000,000 억원 · 누락 시 1.2 억원

영업이익률과 추정 영업비용(매출 − 영업이익)의 기준입니다. GDP·물가 변화에 따른 추정 이익은 별도로 표시합니다.

### 연간 순이익

-1,000,000~1,000,000 억원 · 누락 시 0.8 억원

EPS·PER·ROE와 재무 참조 주가의 기준입니다. 순이익이 양수일 때 EPS × 참조 PER를 사용하며, 0 이하이면 양수 BPS를 사용합니다.

### 자산총계

0~1,000,000 억원 · 누락 시 6 억원

부채를 빼 자본총계를 구합니다. 자본을 모형 주식 수로 나누어 BPS를 계산합니다.

### 부채총계

0~1,000,000 억원 · 누락 시 2 억원

자산에서 차감해 자본을 구하며 부채비율에도 사용합니다. 회사 부채가 참여자의 차입금으로 옮겨가지는 않습니다.

### 참조 PER

1~1,000 배 · 누락 시 10 배

흑자 회사의 재무 참조 주가를 계산할 때 EPS에 곱하는 가정입니다. 현재가로 계산한 화면의 PER와 구분합니다.

### 재무정보 반영도

0~100 % · 누락 시 0 %

시작가와 재무 참조 주가를 혼합할 비중입니다. 0%는 시작가, 100%는 재무 참조 주가를 판단 기준으로 사용합니다. 최저 기준은 1원이며 실제 주가는 체결로 결정됩니다.

### 재무 지표 계산

모형 주식 수는 참여자 초기 보유량의 합계입니다. 시가총액 = 현재가 × 주식 수, EPS = 순이익 ÷ 주식 수, BPS = (자산 − 부채) ÷ 주식 수입니다. 현재가가 변하면 시가총액·PER·PBR도 갱신합니다.

PER는 시가총액 ÷ 양수 순이익, PBR는 시가총액 ÷ 양수 자본입니다. ROE는 순이익 ÷ 기말 자본, 부채비율은 부채 ÷ 자본입니다. 계산할 분모가 0 이하이면 적자·자본잠식 등 상태를 표시합니다.

### 재무·거시 → 주문 가격

시작가 × (1 − 재무 반영도) + 재무 참조 주가 × 재무 반영도로 판단 기준을 만듭니다. 여기에 거시경제 평가 배수를 곱해 1원 이상으로 제한합니다. 주식 수가 없으면 시작가를 재무 기준으로 씁니다.

판단 기준은 주문 호가의 재료입니다. 실제 가격을 그 값으로 옮기지 않습니다. 재무 반영도 0%여도 거시 반영도가 있으면 거시 조정은 적용됩니다. 실적·재무 입력과 경기 추정치는 구분해 표시합니다.

-2~30 % · 누락 시 3 %

### 거시경제 반영도

0~100 % · 누락 시 100 %

GDP·물가·금리 시나리오의 반영 비중입니다. 0%면 경기 조정을 끄며 재무정보 반영도와 독립적으로 작동합니다.

### GDP 민감도

GDP 성장률 차이에 대한 매출 민감도입니다. GDP가 2%에서 5%가 되고 민감도가 1.8이면, 거시 반영도 100%에서 추정 매출은 5.4% 증가합니다.

물가 변화가 영업비용에 미치는 크기입니다. 높을수록 기준보다 높은 물가가 추정 이익을 더 크게 깎습니다.

### 금리 민감도

0~20 배

금리 차이에 따른 평가 배수의 민감도입니다. 금리가 높아지면 참조 PER·평가 배수가 낮아지고, 낮아지면 높아지는 모형입니다.

### 경기순환주·방어주·중립형

경기순환주: GDP 민감도 1.8, 물가 비용 민감도 0.75, 금리 민감도 6. 유형을 고르면 기본 민감도를 불러오며 이후 각 수치를 바꿀 수 있습니다.

경기방어주: GDP 민감도 0.35, 물가 비용 민감도 0.25, 금리 민감도 4. 유형을 고르면 기본 민감도를 불러오며 이후 각 수치를 바꿀 수 있습니다.

중립형: GDP 민감도 1, 물가 비용 민감도 0.5, 금리 민감도 5. 유형을 고르면 기본 민감도를 불러오며 이후 각 수치를 바꿀 수 있습니다.

### 경기 → 추정 실적

GDP 기준 차이와 민감도로 매출 변화를 추정합니다. 비용의 70%는 매출에 따라 변하는 것으로 가정하며, 물가 상승은 비용 민감도에 따라 이익을 깎습니다. 이익 변화를 추정 영업이익·순이익에 더합니다.

금리 차이는 지수 함수로 평가 배수를 조정합니다. 추정 이익과 금리 효과를 합친 평가 배수는 0.1~3배로 제한합니다. 고정 연간 시나리오이며 가상 10초마다 GDP나 실적을 누적하지 않습니다.

## 직접 거래·레버리지

### 내 자금 · 금액 입력·무제한

시장 설정 → 시장 기본에서 원하는 초기 자금을 만원 단위로 입력하거나 ‘무제한 ∞’를 선택합니다. 무제한에서는 자금·신용·담보 부족으로 내 주문을 제한하거나 반대매매하지 않습니다.

무제한이어도 실제 상대 주문이 있어야 체결되며, 일반 매도는 보유 주식 내에서 가능합니다. 체결된 금액과 보유 주식으로 손익을 계산하고, 초기 자금 대비 수익률은 계산하지 않습니다. 자금 설정 방식은 금액과 함께 저장됩니다.

### 시장가·지정가·공매도

내 시장가 주문은 상대 지정가 중 좋은 가격부터 체결하고 남은 수량은 해당 틱에 취소합니다. 지정가 잔량은 체결·취소까지 유지합니다. 같은 종목의 내 대기 주문은 하나이며, 매도는 보유 주식 내에서 가능합니다.

공매도는 빌린 주식을 팔아 음수 보유량을 만듭니다. 전체 담보 한도를 지키며 매수로 되갚을 수 있습니다. 매수·공매도 모두 실제 상대 주문이 있어야 체결됩니다.

### 공유 신용·담보·예약

금액 입력 방식에서는 내 초기 자금과 1~3배 레버리지를 모든 종목에 공통으로 적용합니다. 신규 차입 한도 = 초기 자금 × (배수 − 1), 총 포지션 한도 = 현재 순자산 × 배수입니다. 대기 주문은 다른 주문의 여력을 예약해 둡니다.

공매도 한도는 초기 재산과 현재 순자산 중 작은 값의 위험감수별 10~75%입니다. 내 계좌는 75% 기준입니다. 내 레버리지를 바꾸면 모든 종목 대기 주문을 취소해 예약을 해제합니다. 자금 무제한 방식은 이 자금·신용·담보 한도를 적용하지 않습니다.

### 내 거래와 참여자 반응

내 주문이 체결되면 가격·거래량·거래 상대의 재산이 바뀝니다. 다음 틱에는 참여자가 이 확정된 결과를 보고 반응합니다. 직접 거래의 반응 화면에서 이후 주문과 이유를 확인합니다.

주문 전후 가격에는 같은 틱의 다른 거래도 포함됩니다. 이후 참여자 판단에는 기업 소식·감정 등도 작용합니다. 표시한 변화 전체를 내 주문 하나의 효과로 분리한 값은 아닙니다.

### 반대매매

전체 포지션 절댓값의 합계가 순자산 × 최대 레버리지 × 1.12를 넘거나, 포지션이 있는데 순자산이 소진되면 보유 축소를 시도합니다. 일반 행동의 확률·사이드카 감축보다 우선합니다.

서킷브레이커 중에는 반대매매 체결도 멈춥니다. 거래 재개 후 상대 주문이 없으면 청산이 미체결될 수 있으며, 청산 손실로 신용 한도를 넘거나 순자산이 음수가 될 수 있습니다.

## 시장 안정장치

### 안정장치의 시장 지수

종목별 현재가 ÷ 시작가를 같은 비중으로 평균해 시작값 100의 지수를 만듭니다. 사이드카는 관찰 구간의 등락, 서킷브레이커는 시작 지수 대비 하락을 봅니다. 실제 거래소 제도와 다른 조절 가능한 모형입니다.

### 사이드카의 효과

기본값은 최근 1분 지수 ±5%에 발동, 5분 지속, 참여 비율 15%, 재발동 대기 5분입니다. AI는 원래 판단 확률에 앞서 참여 추첨을 통과해야 하며 주문량·호가 적극성도 줄입니다.

반대매매와 내 직접 주문은 사이드카 감축에서 제외합니다. 위험감수 자체는 바꾸지 않고, 화면의 주문 열기는 위험감수 × 현재 참여 비율로 표시합니다.

### 서킷브레이커의 효과

기본 하락 기준은 시작 지수 대비 8%·15%·20%이며 단계별 20분 동안 전체 종목 거래를 멈춥니다. 각 단계는 실험당 한 번 발동하고 급락하면 상위 단계로 바로 진입합니다.

중단 중에는 AI·내 주문·반대매매의 체결이 없습니다. 시간과 발표 일정·감정 회복은 진행합니다. 새 직접 주문은 막고 기존 지정가·예약은 유지하며 취소는 허용합니다.

### 해제·회복·시험 발동

기본 회복 시간은 3분입니다. 서킷브레이커 뒤 참여·주문 강도는 25%부터, 사이드카 뒤에는 설정 참여 비율부터 정상으로 회복합니다. 시장 안정 화면에서 발동·해제 기록을 봅니다.

시험 발동 버튼은 가격이나 재산을 조작하지 않고 장치 상태만 바꿉니다. 가상 시간을 진행해야 지속 시간이 줄어듭니다. 각 기준·시간·참여 비율은 시장 설정에서 바꿀 수 있습니다.

## 차트·결과·저장 범위

### 캔들·이동평균·기록

실제 체결로 시가·고가·저가·종가·거래량을 기록합니다. 현재 봉은 진행 중이며 20·60개 봉이 쌓이면 이동평균선을 표시합니다. 1분·5분봉, 확대·이동·십자선으로 관찰할 수 있습니다.

최근 1,200개 1분봉과 체결 내역 40건을 보관합니다. 누적 지표는 실험 전체를 반영합니다. 순자산은 현금 − 차입금 + 각 종목 주식 평가액이며, 음수 보유량은 상환해야 할 공매도입니다.

### 설정·실험 초기화

설정 적용은 현재 브라우저에 구성을 저장하고 모든 종목·내 계좌를 새로 시작합니다. 초기화는 적용한 같은 설정과 시드로 재시작합니다. 실행 중 가격·감정·주문·직접 발동 이슈는 새로고침 후 이어지지 않습니다.

### 현재 계산 범위

실제 시세를 연결하지 않은 가상 시장입니다. 인버스·인덱스 상품, 거래 이자·수수료·세금·대차료, 환율·해외시장, 실적 자동 공시는 아직 반영하지 않습니다. 경기·뉴스·감정의 계수는 이 앱의 모형 가정입니다.

## 설명 갱신 방법

참여자 속성을 추가할 때 `PARTICIPANT_ATTRIBUTES`와 `PARTICIPANT_HELP`를 함께 갱신합니다. 판단 순서·체결·뉴스·거래량·감정 등 동작을 바꾸면 해당 `HELP_SECTIONS` 항목도 수정합니다.

`node scripts/build-simulation-reference.cjs`로 이 문서를 갱신합니다. `--check`는 누락·중복 설명과 문서의 최신 여부만 확인하며 매매 실험을 실행하지 않습니다.
