# 프로젝트 검토 및 개선 기록

검토일: 2026-09-07

## 기존 구조와 발견 사항

Python 빌드 기반 정적 사이트다. 본문은 경제·금융투자·재무설계·법률의 네 분야에 121개 심화 단원과 별도 용어사전으로 구성되어 있다. 본문을 재사용하면서 입문 설명과 심화 읽기를 연결하는 방향으로 개선했다.

| 발견 사항 | 반영한 변경 |
| --- | --- |
| 분야 선택 위주의 홈, 개념 연결 부족 | 질문별 학습 경로 4개, 클릭형 핵심 개념 12개 |
| 초보자가 긴 본문과 전문용어를 바로 접함 | 쉬운 정의·숫자 예시·심화·비교표·오해·출처 패널 |
| 검색 결과가 분야 첫 화면으로만 이동 | 사전 항목 및 검색된 심화 단원을 직접 펼쳐 이동 |

| 계산기 빈값·음수 등 비정상 입력 처리 부족 | 입력 범위·유한값 검증, DCF 성장률 조건 처리 |

| URL과 화면 상태 연결 부족 | 화면별 해시 주소와 뒤로 가기 |

## 콘텐츠 근거

새 예시는 실제 투자 실적이나 시장 전망이 아니라 계산 원리를 설명하는 가정이다. 제도 관련 설명은 적용 대상과 사실관계의 확인 필요성을 포함하며, 임의로 현재 한도·세율을 확정하지 않았다.

- 통화정책 전달경로: [한국은행](https://www.bok.or.kr/portal/main/contents.do?menuNo=200289)
- 채권 및 금리·신용위험: [SEC Investor.gov](https://www.investor.gov/introduction-investing/investing-basics/investment-products/bonds-or-fixed-income-products/bonds)
- FCFF·WACC·말기가치: [NYU Stern, Aswath Damodaran](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/lectures/val.html)
- 적합성 적용 장면: [국가법령정보센터 제17조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031294303)
- 일별 기준환율 성격, 제공처 필터와 시계열: [Frankfurter 공식 문서](https://frankfurter.dev/)
- 거래소 스냅샷·등락 기준: [업비트 현재가 API](https://docs.upbit.com/kr/reference/list-tickers)

## 검증 범위

- 최종 브라우저 기능 검증 67개 통과. 390px 너비에서 8개 화면의 문서 너비가 모두 390px임을 확인했다.
- Python 빌드와 JavaScript 문법 검사.
- 실제 로컬 브라우저에서 환율, BTC·ETH 현재가 및 환율 이력 조회 성공 확인.
- 개념 경로, 설명 모드, 분야와 목차 탐색, 검색한 단원 펼치기, 용어 검색, 계산 입력 경계값 회귀 검증.
- 별도 테스트 응답으로 정상·부분실패·전체실패·저장값 사용·저장값 없음 처리 검증. 가상 응답은 제품 데이터에 포함하지 않는다.
- 데스크톱 및 390px 모바일 화면 시각 검증. 모바일 개념 지도의 그리드 최소 너비로 인한 가로 넘침 수정.

## 남은 확장·한계

- 한국 거시지표 자동 연동은 ECOS/KOSIS 공급자별 인증과 서버 캐시를 추가하는 다음 범위다. 현재 공식 링크와 미연동 상태를 명시한다.
- KRX 실시간 지수·주식 시세는 적절한 제공 계약과 공급자 선택이 선행되어야 한다.
- 기존 12만 자 이상 원문 전체의 최신 세법·법령·상품 제도에 대한 조문별 재검증은 완료로 간주하지 않는다. 법률·세제 단원에는 출처·시행일·검토 상태를 구조화하는 후속 편집이 필요하다.
- 현재 인쇄본은 기존 챕터 기반이다. 새 개념 지도와 시장 데이터는 웹 기능이며, 실시간 데이터는 인쇄 문서에 고정하지 않는다.
- 학습 기록은 기기별이며 로그인·기기 간 동기화는 없다.
- 이번 변경은 로컬 구현·빌드·검증이며 원격 배포는 실행하지 않았다.

## 2026-10-17 개편 검증

109개 개념을 독립된 원고(`content/fieldbook.json`)로 재작성하고 서재, 개념 사전, 개념 연결, 리마인드, 북마크, 실험실, 시장 데이터 화면으로 교체했다. 기존 원자료는 `source/`에 보존하며 개편 전 파일은 `artifacts/before-rewrite/`에 복사했다.

- `python scripts/build.py`: 109개 개념, 네 분야, 인쇄본 생성 성공.
- `scripts/verify-fieldbook.cjs`: 전체 개념 경로와 검색·저장·복습·계산·모바일을 포함한 173개 확인 통과. 결과는 `artifacts/verification.json`.
- `scripts/verify-markets.cjs`: 정상 응답, 저장값 fallback, 잘못된 응답, 저장값 없는 오류, 화면 전환 확인. 실제 ECB/Frankfurter와 업비트 요청 세 개 모두 HTTP 200. 결과는 `artifacts/market-verification.json`.
- 최종 교정: 인수합병 순가치식의 독립가치 누락 수정, 산출갭률 단위 표시, GNI의 거주자 기준 명시, 분야별 참고자료 연결 보강.
- 보조 확인: 이전 챕터 주소 이동, 잘못된 주소 처리, 복습 버튼의 접근성 상태, 모션 감소 설정, `git diff --check` 통과.
- 세법·법률은 개념과 적용 판단 구조를 설명한다. 전체 조문이나 모든 최신 개정의 법률 감수를 완료했다는 의미는 아니다.

원고와 기능은 로컬 빌드에 반영됐으며 원격 배포는 실행하지 않았다.
