# Finance Fieldbook

자격증 공부에서 익힌 경제·금융 지식을 다시 꺼내 보는 개인 서재입니다. 원자료의 범위와 아이디어를 바탕으로 설명·예시·개념 간 연결을 새로 작성했습니다.

## 실행

```powershell
python scripts/build.py
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:8765 에서 확인합니다. 앱이 JSON을 읽으므로 HTTP 서버가 필요합니다. `dist/finance-guide-print.html`은 직접 열거나 브라우저에서 인쇄/PDF로 저장할 수 있습니다.

## 구성

- 경제 / 금융·투자 / 재무설계 / 법률·윤리의 109개 개념 카드.
- 핵심 문장 → 공식·구조 → 숫자 예시 → 펼쳐 보는 원리 → 헷갈리는 점.
- 전체 검색(Ctrl/Cmd K), 분야·주제·복습 상태 필터, 관련 개념과 다섯 가지 연결 경로.
- 북마크, 개인 메모, 기억남/다시 보기 상태, 한 번에 최대 5개씩 회상하는 복습.
- 채권·금리, 포트폴리오 상관, 복리·과세 시점, DCF 민감도, AD–AS, 비상자금의 여섯 개 실험.
- 모바일 화면, 키보드 검색, 모션 감소 설정, 같은 원고에서 만드는 인쇄용 노트.

개인 기록은 현재 브라우저의 localStorage에만 저장합니다. 로그인·기기 간 동기화는 없습니다. 데이터를 삭제하면 기록도 사라집니다. 저장이 제한된 브라우저에서는 현재 세션 안에서 동작합니다.

## 편집 위치

| 경로 | 역할 |
| --- | --- |
| `source/` | 사용자의 원자료 보존 |
| `content/fieldbook.json` | 개념, 연결, 관련 출처의 기준 원고 |
| `content/chapters/` | 빌드가 생성하는 분야별 Markdown 및 사전 |
| `site/app.js` | 화면과 개인 복습 기능 |
| `site/labs.js` | 실험 목록·화면·계산 함수 |
| `site/markets.js` | 시장 데이터 조회·검증·실패 처리 |
| `site/styles.css` | 반응형 레이아웃·모션·인쇄 스타일 |
| `scripts/build.py` | 원고 검증 후 `dist/` 생성 |
| `artifacts/before-rewrite/` | 개편 전 로컬 파일 백업 |

새 개념은 JSON에 고유 ID를 지정해 추가합니다. 연결 경로와 관련 개념에는 해당 ID를 사용합니다. 새 실험은 `LABS` 목록, `labMarkup`, `mountLab`에 추가하고 개념의 `lab` 필드로 연결합니다. `scripts/author_content.py`는 최초 재작성 원고를 생성한 기록이며, 이후 편집은 JSON에서 합니다. 예전 `explorer`·`knowledge` 파일은 이전 작업 보존용으로 남아 있으며 현재 화면에서는 로드하지 않습니다.

## 자료와 계산의 범위

개념 카드는 복습용으로 압축한 설명입니다. 세율·공제 한도 등 시점에 따라 달라지는 숫자를 상수로 제시하지 않고 법령과 공식 안내를 연결합니다. 각 실험은 가정을 화면에 표시하며, 금융상품 수익이나 실제 거시경제를 예측하는 모형은 아닙니다.

## 시장 데이터

- 원·달러: Frankfurter v2의 ECB 자료, 일별 공시와 최근 30일 이력. 1시간 로컬 캐시.
- BTC·ETH: 업비트 공개 REST API, 화면이 보일 때 60초 간격 조회.
- 기준일·시세 시각·제공처를 표시합니다. 수동 새로고침은 캐시를 우회합니다.
- HTTP 상태와 응답 형식을 검증하고 요청당 12초 제한을 둡니다. 실패하면 이전 저장값임을 표시하거나 조회 불가 상태를 안내합니다.
- 화면 이탈 시 요청과 갱신 타이머를 중단합니다. 개인 기록은 제공처에 전송하지 않습니다.

## 배포

`dist/`가 정적 배포 대상입니다. 기존 GitHub Pages 워크플로를 사용할 수 있습니다. 이번 개편은 로컬에서 빌드·확인하며, 배포는 별도 실행입니다.

## 검증 기록

2026-10-17 로컬 브라우저에서 전체 개념 경로와 주요 사용자 흐름 173개 확인을 통과했습니다. 시장 데이터는 정상·실패·캐시 응답을 구분해서 검사했고 ECB/Frankfurter 및 업비트의 실제 HTTP 200 응답도 확인했습니다. 검증 상세와 화면 캡처는 `artifacts/`에 있습니다. 브라우저 검증 스크립트는 로컬에 설치된 Playwright와 Edge를 사용합니다.
