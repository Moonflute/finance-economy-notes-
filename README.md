# Finance Fieldbook

경제·금융·재무설계·법률의 개념과 원리를 읽는 참고서입니다. 사용자가 정리한 원자료의 범위와 아이디어를 바탕으로 설명과 예시를 새로 작성했습니다.

## 실행

```powershell
python scripts/build.py
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:8765 에서 확인합니다. 앱은 JSON을 읽으므로 HTTP 서버가 필요합니다. `dist/finance-guide-print.html`은 직접 열거나 브라우저에서 인쇄/PDF로 저장할 수 있습니다.

## 구성

- 첫 화면에는 경제 / 금융·투자 / 재무설계 / 법률·윤리의 네 분야만 표시합니다.
- 개념 사전은 분야·주제별 카드와 제목·본문 검색을 제공합니다. 전체 검색은 Ctrl/Cmd K로 엽니다.
- 109개 개념마다 네 문단의 서술형 본문으로 정의, 작동 원리, 사례와 해석을 설명합니다. 본문은 접지 않고 이어서 표시하며 공식·구조를 함께 배치합니다.
- 북마크와 관련 개념 링크를 제공합니다. 복습 체크, 진도, 회상 카드, 학습 추천 기능은 없습니다.
- 채권·금리, 포트폴리오 상관, 복리·과세 시점, DCF 민감도, AD–AS, 비상자금의 여섯 가지 계산 도구를 제공합니다.
- 모바일 화면, 키보드 검색, 모션 감소 설정을 지원합니다. 인쇄본은 웹과 같은 본문에서 생성합니다.

북마크는 현재 브라우저의 localStorage에 저장됩니다. 로그인·기기 간 동기화는 없습니다. 저장이 제한된 브라우저에서는 현재 페이지 세션에서만 유지됩니다. 이전 버전의 메모와 복습 기록은 사용하지 않으며 기존 저장값은 덮어 지우지 않습니다.

## 편집 위치

| 경로 | 역할 |
| --- | --- |
| `source/` | 사용자 원자료 |
| `content/fieldbook.json` | 개념 본문, 사전 요약, 관련 개념과 출처의 기준 원고 |
| `content/chapters/` | 빌드로 생성하는 분야별 Markdown 및 사전 |
| `site/app.js` | 분야·사전·본문·북마크 화면과 검색 |
| `site/labs.js` | 계산 도구와 수식 |
| `site/markets.js` | 시장 데이터 조회·검증·실패 처리 |
| `site/styles.css` | 반응형 레이아웃·모션·인쇄 스타일 |
| `scripts/build.py` | 원고와 연결을 검증하고 `dist/` 생성 |
| `scripts/verify-fieldbook.cjs` | 본문·검색·북마크·계산·모바일·인쇄본 브라우저 검증 |
| `scripts/verify-markets.cjs` | 시장 데이터 응답과 실패 상태 검증 |
| `artifacts/before-rewrite/` | 개편 전 파일 백업 |

새 개념은 JSON에 고유 ID를 지정해 추가합니다. `summary`는 사전 카드의 짧은 설명이며, `body` 배열은 본문 문단입니다. `formula`는 본문의 두 번째 문단 다음에 표시합니다. `related`에는 관련 개념 ID를, `sources`에는 출처 ID를 사용합니다. 이전 원고의 `cue`, `detail`, `example`, `trap`, `paths`는 편집 이력으로 보존하며 현재 본문 화면에 사용하지 않습니다.

새 실험은 `LABS` 목록, `labMarkup`, `mountLab`에 추가하고 개념의 `lab` 필드로 연결합니다. `scripts/author_content.py`는 최초 원고 생성 기록이므로 현재 JSON에 다시 실행하지 않습니다. 예전 `explorer`·`knowledge` 파일은 이전 작업 보존용이며 현재 화면에서 로드하지 않습니다.

## 자료와 계산의 범위

원고는 개념과 판단 구조를 설명합니다. 시점에 따라 달라지는 세율·공제 한도 등을 고정된 현재 값으로 제시하지 않고 법령과 공식 안내를 연결합니다. 각 계산 도구는 가정을 화면에 표시하며 실제 금융상품 수익이나 거시경제의 예측을 보장하지 않습니다.

## 시장 데이터

- 원·달러: Frankfurter v2의 ECB 자료, 일별 공시와 최근 30일 이력. 1시간 로컬 캐시.
- BTC·ETH: 업비트 공개 REST API, 화면이 보일 때 60초 간격 조회.
- 기준일·시세 시각·제공처를 표시합니다. 수동 새로고침은 캐시를 우회합니다.
- 요청이 실패하면 이전 저장값임을 표시하거나 조회 불가 상태를 안내합니다.
- 화면 이탈 시 요청과 갱신 타이머를 중단합니다. 북마크 등 개인 기록은 제공처에 전송하지 않습니다.

## 검증 및 배포

2026-10-20 기준 v0.2.0을 로컬에서 빌드하고 167개 브라우저 확인을 통과했습니다. 전체 109개 본문, 기존 북마크 보존, 본문 검색, 계산 도구, 320px·390px 모바일 가로 넘침, 인쇄본 일치 여부를 확인했습니다. 결과와 화면 캡처는 `artifacts/reference-v2/`에 보관합니다. 스크립트는 로컬 Playwright와 Edge를 사용하며, 서버 주소는 `FIELDBOOK_URL` 환경변수로 지정할 수 있습니다.

`dist/`가 정적 배포 대상이며, GitHub Pages 워크플로는 `main` 푸시로 실행됩니다. 배포 주소는 https://moonflute.github.io/finance-economy-notes-/ 입니다. 배포 후 점검과 임시 파일 정리는 `AGENTS.md`를 따릅니다.
